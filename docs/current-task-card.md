# 当前任务卡
Updated: 2026-05-15

## 这份文档的定位
这份文档是 `Gemini-Lab` 的 `L1 当前任务卡`，只承载“当前这一轮任务”的最小必要上下文。

它服务于：
- 当前任务目标
- 当前任务边界
- 当前任务完成标准
- 当前轮次明确不做什么

与它配套的机器可检查版本是：
- `docs/current-task-card.json`

## 使用规则
1. 每当进入新的明确任务阶段时，先更新这份任务卡，再执行修改或 git 操作。
2. 这份文档应尽量短，避免变成第二套长期记忆。
3. 任务边界改变时，必须先重写任务卡，再继续执行。
4. 进入任何写操作前，应先通过 `tools/check-task-gate.ps1`。
