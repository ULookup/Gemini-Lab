# 当前任务卡

Updated: 2026-05-12

## 这份文档的定位
这份文档是 Gemini-Lab 的 L1 轻量任务卡，用于承载“当前这一轮任务”的最小必要上下文。

它不记录完整历史，不替代 `docs/ai-memory/` 的长期记忆，只服务于：
- 当前任务目标
- 当前任务边界
- 当前任务完成标准
- 当前轮次明确不做什么

## 使用规则
1. 每当进入新的明确任务阶段时，先更新这份任务卡，再执行修改。
2. 这份文档应尽量短，避免重新长成“第二套长期记忆”。
3. 任务结束后，可以清空或替换为下一轮任务卡内容，不要求长期保留所有细节。
4. 如果任务边界改变，必须先重写任务卡，再继续执行，不要沿用上一轮任务卡。
5. 如果用户只要求检查或讨论，也应该先把“当前任务 / 本轮明确不做 / 完成标准”写清楚。
6. 默认情况下，任务卡应在进入“行动”阶段前完成第一次填写。
