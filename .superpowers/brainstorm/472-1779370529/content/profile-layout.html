Profile 页面布局方案

PetStatus 面板升级 —— 素材包括：背景图、状态图标、导航按钮

A

卡片式

顶部：背景图区域（Angel/Devil 切换），前景叠加宠物名 + Title 图标
中部：3 个状态项（Energy / Mood / Relationship），图标 + 数值
底部：4 个导航按钮（Collection | onProfile | SpaceSys | Tarot）

B

全幅背景式

整面板填充背景图，所有内容叠加在背景之上
状态指标散布在宠物形象周围，导航按钮透明叠加在底部

C

混合式（保留雷达图）

左侧：背景图 Profile 卡片
右侧：保留现有的 7 维性格雷达图
底部：导航按钮
状态图标嵌入左侧卡片中
